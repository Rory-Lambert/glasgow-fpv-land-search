# Club members

Postcodes of club members, used to work out how far each site is from everyone
(see [`analysis/members.py`](../analysis/members.py) and the travel report added
to each site issue).

Add a member as a new table row. A full postcode (`G31 2AB`) is most accurate; a
postcode district / outcode (`G31`) works too and is geocoded to the district
centroid. Keep it to postcode only — no names or addresses — so this stays
shareable without exposing anyone's home.
